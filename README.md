# 점심 식당 수첩 (1인 로컬 버전)

내 단골 점심 식당을 모아 두고, 카테고리·태그 필터와 랜덤 추천으로 오늘 갈 곳을 고르는 1인용 PWA입니다.
서버와 DB 없이 동작하며, 모든 데이터는 기기 안(IndexedDB)에만 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 진입점 |
| `app.css` | 화면 스타일 (라이트·다크) |
| `js/app.js` | 화면과 동작 |
| `js/store.js` | 저장 계층 (팀 버전에서 서버 API로 교체할 부분) |
| `sw.js` | 서비스 워커 (오프라인 실행) |
| `manifest.webmanifest`, `icons/` | 홈 화면 아이콘과 앱 정보 |

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. 무료 계정은 공개(Public) 저장소여야 Pages를 쓸 수 있습니다.
2. 이 폴더의 파일과 폴더를 모두 저장소 최상위에 올립니다. `index.html`이 최상위에 있어야 합니다.
3. 저장소의 Settings → Pages → Build and deployment에서 Source를 "Deploy from a branch"로,
   Branch를 `main` / `/ (root)`로 고르고 저장합니다.
4. 1~2분 뒤 `https://<계정>.github.io/<저장소 이름>/` 주소로 열립니다.

## iPhone에 설치

1. 위 주소를 Safari로 엽니다. (카카오톡 등 앱 안의 브라우저에서는 설치할 수 없습니다.)
2. 공유 버튼 → "홈 화면에 추가" → "추가"를 누릅니다.
3. 홈 화면의 "식당 수첩" 아이콘으로 실행합니다.

Safari 탭과 홈 화면 앱은 데이터를 따로 저장하므로, 식당 등록은 홈 화면 앱에서 시작하세요.

## 수정 후 다시 배포할 때

파일을 고쳐 올린 뒤 `sw.js`의 `CACHE` 이름 숫자를 올리면(`lunch-notebook-v2`) 이전 캐시가 정리됩니다.
주소(도메인과 경로)를 바꾸면 저장된 데이터가 따라오지 않으므로, 먼저 데이터 관리에서 내보내기를 해 두세요.
